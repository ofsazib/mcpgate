# Contributing to mcpgate

Thanks for contributing! The full engineering contract — setup, architecture,
conventions, testing policy, PR checklist — lives in [AGENTS.md](AGENTS.md).
Read it before opening a PR.

Quick version:

```bash
uv sync --all-extras
uv run pytest
uv run ruff check .
uv run mypy src
```

By participating you agree to the [Code of Conduct](CODE_OF_CONDUCT.md).
